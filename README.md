# TFA Splits Tracker

Room splits, raid times, and party history for The Fractured Archive in RuneLite.

[![Active Installs](https://img.shields.io/endpoint?url=https://api.runelite.net/pluginhub/shields/installs/plugin/tfa-splits-tracker)](https://runelite.net/plugin-hub/show/tfa-splits-tracker)
[![Plugin Rank](https://img.shields.io/endpoint?url=https://api.runelite.net/pluginhub/shields/rank/plugin/tfa-splits-tracker)](https://runelite.net/plugin-hub/show/tfa-splits-tracker)

## Features

- Automatically track server-reported room splits and total raid times.
- View live timings in the sidebar, overlay, chat, and infoboxes.
- Browse saved raid history by day, team size, party member, or result.
- Compare up to five raids side by side with time differences against a chosen baseline.
- Manage saved raids and splits, with undo for your last deletion.

History is saved separately for each RuneScape profile and kept between sessions.
